Langfuse vs Helicone vs Braintrust: what they're like to use

Langfuse is the open platform you can own, Braintrust is the managed eval workbench, and Helicone is the gateway that logs what passes through.

Langfuse

The broadest open-source option: traces, versioned prompts, LLM-as-a-judge evaluators, datasets and experiments in one product, built on OpenTelemetry. You instrument your code with an SDK or integration.

What I liked

  • Cheapest paid entry point at $29 a month, with unlimited users on paid plans.
  • Self-hosting is a documented, first-class path, per Langfuse.
  • Alerts can reach Slack or webhooks.

What I didn't

  • Self-hosting needs Postgres, ClickHouse, Redis and blob storage.
  • Scores and observations count as billable units, so eval work adds to the bill.
  • Some features need a license key, and ee/ folders use a separate license.

Best for: teams that want tracing and evals they can inspect, extend and run themselves.

Helicone

The quickest way to get logs and cost data: point your OpenAI-style client at its gateway and every request is recorded with cost, latency and errors. It is a gateway first and an evals tool second, and it is now in maintenance mode.

What I liked

  • Base-URL change gets you logging, with fallbacks across 100+ models.
  • Cost breakdowns by user or feature.
  • Apache-2.0 code you can run with Docker.

What I didn't

  • Maintenance mode means no new features are planned, per Mintlify.
  • The pricing page does not list per-request usage rates.
  • Its docs overview says little about evals or scoring.

Best for: teams that mainly need gateway logging and cost tracking and accept a maintenance-mode roadmap.

Braintrust

Evaluation is the center of gravity: experiments, datasets, scorers and an in-product agent called Loop, with tracing feeding them. It accepts OpenTelemetry traces.

What I liked

  • Strongest eval workflow of the three, from datasets to experiments.
  • Six SDK languages, an MCP server and a CLI.
  • Slack alerts and webhook-based sustained score alerts.

What I didn't

  • Entry paid plan is $249 a month, the highest of the three.
  • Several meters: data, scores, retention, credits.
  • Self-hosting is Enterprise only, with a control plane Braintrust runs.

Best for: teams where evals gate releases and a managed platform is acceptable.

Which to choose

  • Choose Langfuse if you want open-source tracing and evals with the lowest entry price and the option to self-host.
  • Choose Helicone if you mainly need a gateway with logs and cost tracking and can live with maintenance mode.
  • Choose Braintrust if evals and release gating matter most and you prefer a managed platform.

FAQ

What is the difference between Langfuse, Helicone and Braintrust?

Langfuse is open-source tracing, prompts and evals. Helicone is an AI gateway that logs requests and tracks cost. Braintrust is a hosted platform centered on evals, datasets and tracing.

Is Helicone still maintained?

Per Mintlify, which acquired it, Helicone continues in maintenance mode with security updates, bug fixes and support for new models. No new feature development is promised.

Is Langfuse still open source after the ClickHouse acquisition?

Per Langfuse, yes: it stays open source and self-hostable, with no planned license changes. The core is MIT.

How much does Langfuse cost at 1M units a month?

On Core it is $101: $29 for the first 100k units plus $8 per 100k for the next 900k. On Pro it is $271.

Can I self-host Braintrust?

Only on the Enterprise plan, as a hybrid setup. You run the data plane and Braintrust runs the control plane.
