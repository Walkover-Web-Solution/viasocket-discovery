# Nango vs Pipedream Connect: pricing and features

URL: https://viasocket.com/discovery/compare/nango-vs-pipedream-connect
Author: Jatin Kashiv (https://viasocket.com/discovery/user/79503)
Publisher: viaSocket Discovery
Note: vendor claims are attributed, for example "per Nango".

## Short answer
Nango is code-first: you write and own TypeScript functions, and its free plan covers 10 connections. Pipedream Connect lists 3,000+ APIs (per Pipedream; its own docs also say 2,500+), but its free tier is development only and production starts at $99 a month billed annually. Workday says it closed its acquisition of Pipedream.

## Features
- Approach: Nango is TypeScript functions you own (per Nango). Pipedream Connect is a toolkit for embedding integrations with code-level control (per Pipedream).
- APIs: Nango 1,000+ APIs (per Nango, https://nango.dev/docs). Pipedream 3,000+ APIs on its Connect docs (https://pipedream.com/docs/connect), 2,500+ APIs on its managed auth page (https://pipedream.com/docs/connect/managed-auth) and 10,000+ tools in its MCP server (per Pipedream). Counts differ across its own pages.
- Auth: Nango OAuth, API keys, token refresh, scopes. Pipedream managed auth with a short-lived token per end user; SDK iframe or Connect Link.
- MCP: both have an MCP server.
- Data sync: Nango scheduled, resumable syncs. Not covered on the Pipedream Connect pages read.
- Open source: Nango is under the Elastic License (source-available), 13.0k GitHub stars. Pipedream's components registry is described as source-available; Connect's license is not stated in its docs.
- Self-hosting: Nango free self-hosting is limited to API auth and proxy per its docs (https://nango.dev/docs/guides/platform/self-hosting); full self-hosting and BYOC need Enterprise. Not mentioned in Pipedream Connect docs.
- Security: Nango SOC 2 Type II and HIPAA with BAA (per Nango). Pipedream SOC 2 Type 2 and GDPR on all plans; SSO, SCIM and HIPAA on Business.

## Pricing
- Nango Free: $0. 10 connections, 10 compute hours, 10 GB data transfer a month. Hard-capped.
- Nango pay-as-you-go: $50 a month, includes $50 of credits, then $0.29 per connection, $0.72 per compute hour, $0.50 per GB.
- Nango Growth add-on: $450 a month. Private Slack and 5 days requested integration delivery time.
- Nango Enterprise: custom. Self-hosting, bring your own cloud, MSA, SLA.
- Pipedream Free: $0. Development only, no production environment.
- Pipedream Startup: $99 a month billed annually or $150 billed monthly. 100 external users included, then $2 each; 10,000 credits a month included, then $0.012 each.
- Pipedream Business: custom, annual contract. SSO, SCIM, HIPAA, dedicated Slack.

## What it's like to use Nango and Pipedream Connect
By Jatin Kashiv. These two overlap on managed auth and MCP, but they feel different the moment you open the docs. Nango wants you to own the integration code. Pipedream Connect wants you to embed a toolkit and lean on its catalog. Hands-on write-ups of Connect are hard to find, so where I cannot tell you how it behaves, I say what I would check.

Nango: the current quickstart is built around agent sessions, for a platform that sells itself on code you own. You copy the environment API key into a backend env file, enable the APIs your agent needs by provider slug, and have your backend call POST /sessions with a stable user ID. The response holds an MCP URL and a session token that you pass to the agent as a remote MCP server, and the first time a user needs an account the agent replies with a connect link. The setup calls are shown with curl and the agent example uses the Vercel AI SDK in TypeScript. The Logs tab shows every tool call, provider request and response, and is the screen to keep open while debugging. Underneath, the product is TypeScript functions that you generate with AI, then edit and version like application code (per Nango), plus scheduled, resumable syncs. That suits you if you want to read and review every integration; it is a bigger commitment than a managed toolkit if all you want is auth. Free self-hosting is a limited option for hobby projects that covers API auth and proxy only, so syncs, tool calls, webhooks and the MCP server are not part of it, and full self-hosting needs Enterprise. Open reports cluster in the same place: a self-hosted connect link sending the Connect UI to Nango's cloud host, a CI environment variable switching the dashboard into a test-auth mode, and a request to clarify the self-hosted feature set. Nango calls itself open source, while the repository names the Elastic License, which is source-available, and early commenters pushed back on the label. If your policy requires an OSI-approved licence, that matters. On OAuth, feedback is positive: one early commenter said it cut their time to integrate and another reported a year of stable use, though that was an earlier version of the product, and some said the unified API label overstated what was then closer to a proxy that handles auth and retries. The free plan is hard-capped at 10 connections, 10 compute hours and 10 GB of data transfer a month. Support is in-app chat, with a private Slack channel only on the $450 Growth add-on or Enterprise.

Pipedream Connect: the quickstart is longer and reads like a checklist for a production-grade embed. Nine steps: set server credentials, create a project and copy its ID, create an OAuth client, generate a short-lived token for each end user on your server, connect the account through the SDK or a Connect Link, make authenticated requests, then test in development before deploying to production. The SDK connects through an iframe; the Connect Link covers places that cannot run JavaScript or an iframe, such as mobile apps, and the URL expires after 4 hours. Examples are in TypeScript and JavaScript. The free tier gives full API, SDK and MCP access, but there is no production environment, and external users and credits are development only. Going live means Startup, at $99 a month billed annually or $150 billed monthly, with 100 external users included (distinct users of your app who connect at least one account), then $2 each, and 10,000 credits a month, then $0.012 each. Actions, MCP tool calls, proxy requests and deployed trigger events each use credits at 1 credit per 30 seconds of compute. Support is community on Free, email on Startup and a dedicated Slack channel on Business. Public rough edges are few, partly because the Pipedream repository is mostly the components registry. Two Connect reports stand out: the React form component cannot reload dynamically configured props, and File Stash in development returns a 401 asking for an upgrade although the environments docs say all Connect features are available in development on any plan. Single reports, not a trend; test any feature you depend on in development first. Workday announced a definitive agreement to acquire Pipedream and says it has since closed the deal. Its announcement does not say how existing customers are affected, and the community discussion included a hope that Pipedream would stay open source alongside a read of the deal as a bad sign. I found no hands-on reports of Connect in that discussion. Before building on it, ask Pipedream or Workday about roadmap and pricing.

How they differ in practice: Nango asks you to own code, and its free plan is hard-capped. Pipedream Connect asks you to adopt its toolkit, and its free tier is development only, so production means paying.

## Which to choose
Nango for code you can read and change, syncs, or self-hosting. Pipedream Connect for managed auth across a very large catalog, with production on a paid plan. Both have free plans, but Pipedream's is for development only.
