## Short answer
Mem0, Zep and Letta all give an AI agent memory, in different ways. Mem0 is a memory layer you add to an existing agent. Zep builds a graph that tracks how facts change over time. Letta is an agent runtime where the agent edits its own memory. Mem0 and Letta are Apache-2.0; Zep's open-source part is Graphiti.

## Mem0 vs Zep vs Letta: what they're like to use
By Jatin Kashiv. The real choice is how much of your stack you hand over: a small API (Mem0), a graph you run or rent (Zep) or the agent runtime (Letta).

### Mem0
The lightest of the three to adopt. You keep your own agent and call a small API to store and retrieve what users have said, which is why it reads as the default pick for adding memory to something that already works.
What I liked:
- A small API: a few calls cover most use cases.
- Apache-2.0 SDK plus a Docker server you can self-host.
- Largest community of the three, at 68.3k GitHub stars.
What I didn't:
- Memories are vector embeddings, so they are hard to read or audit by eye.
- No built-in forgetting or decay for stale facts.
- Mem0's published benchmark scores are from its managed platform, which Mem0 says has optimizations the open-source SDK lacks.
Best for: teams that want persistent per-user memory in an existing agent with minimal code changes.

### Zep
Zep's pitch is that facts change. Its graph records when something was true, so an agent can tell a customer's old address from the current one. That depth comes with more infrastructure than the other two.
What I liked:
- Facts carry timestamps and supersession, so history stays queryable.
- Retrieval, storage and users cost no credits; you pay for episodes written.
- Graphiti runs on Neo4j, FalkorDB or Amazon Neptune.
What I didn't:
- Self-hosting means running a graph database yourself.
- Self-serve paid plans start at $125 a month.
- Graphiti's bundled MCP server is a reference build with no authentication.
Best for: agents that must track how facts change over time and can carry a graph database.

### Letta
Letta is less a memory add-on than a place your agent lives. The agent edits its own memory blocks, with core memory kept in context and the rest paged in on demand, so you adopt its runtime along with its memory.
What I liked:
- The agent edits its own memory blocks, and blocks can be shared across agents.
- A visual environment shows memory changing in real time.
- Entry price of $20 a month, with a free tier to start.
What I didn't:
- You adopt a whole framework, a heavier integration than a memory API.
- Switching agent architectures means exporting and reconfiguring agents.
- Self-editing memory can make debugging harder.
Best for: long-running stateful agents built from scratch that should manage their own context.

## Which to choose
- Choose Mem0 to add memory to an agent you already have, with the least code and a large community.
- Choose Zep if your agent has to reason about what was true when, and you can run or buy a graph.
- Choose Letta if you are building a long-running agent and want it to manage its own context.
Memory quality depends on your data, so run each against a sample of your real conversations before committing.

## FAQ
Q: What is the difference between Mem0 and Zep?
A: Mem0 stores memories as vector embeddings behind a small API. Zep stores facts in a temporal graph that records when each fact was true, which suits data that changes.
Q: Is Letta the same as MemGPT?
A: Letta is the platform that grew out of MemGPT. Its agents edit their own memory blocks, and the open-source runtime is Apache-2.0.
Q: Can I self-host Mem0, Zep or Letta?
A: Mem0 and Letta both offer self-hosting under Apache-2.0. For Zep, only Graphiti, its graph framework, is self-hosted; Zep itself is managed or runs in your cloud.
Q: How much does agent memory cost?
A: Each has a free tier. Paid entry is $20 a month on Letta and $125 a month on Zep Flex. Mem0 lists no self-serve paid price, only a custom plan.
Q: Can I compare them by benchmark score?
A: Not reliably. Mem0 says its managed platform scores 92.5 on LoCoMo and 94.4 on LongMemEval, but those are vendor-published and Mem0 notes the open-source SDK lacks some optimizations. Test finalists on your own conversations.
