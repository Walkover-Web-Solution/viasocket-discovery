n8n vs Activepieces vs Windmill: who each one suits

All three install with Docker and all three can host AI agents. What changes is who they are built for: n8n for the broadest audience, Activepieces for no-code teams, Windmill for engineers.

n8n

The most widely used of the three, with about 209,000 GitHub stars. The editor is a node canvas where you can drop into JavaScript or Python when a node falls short, and the Docker quickstart is one command.

What I liked

  • Huge integration directory: n8n lists 2,000+ on its integrations page.
  • Code nodes with JavaScript, Python and npm packages.
  • MCP server for your whole instance, plus an MCP Server Trigger node.

What I didn't

  • Not OSI open source: the license limits how you can use it commercially.
  • Cloud plans are capped by executions, from 2.5K a month.
  • The Business plan is self-hosted only and costs €667 a month.

Best for: teams that want the largest community and a visual canvas with code escape hatches.

Activepieces

The friendliest of the three for non-developers. Flows are built step by step, every integration is a TypeScript piece, and the installer sets up Docker Compose with PostgreSQL and Redis.

What I liked

  • MIT core, and Activepieces says every piece is MIT.
  • A run costs one credit however many steps it has.
  • Air-gapped self-hosting is supported.

What I didn't

  • Smaller catalog: 770+ pieces, per Activepieces.
  • AI steps cost 2, 10 or 20 credits depending on the model tier.
  • Fewer escape hatches than a code-first tool.

Best for: ops and marketing teams that want an MIT-licensed Zapier alternative.

Windmill

A developer platform more than an app connector. You write scripts in TypeScript, Python, Go, SQL and more, and Windmill turns them into endpoints, forms and flows you can also draw.

What I liked

  • Scripts in 20+ languages become APIs and forms automatically.
  • Retries, approvals and parallel branches are built into flows.
  • MCP works in both directions: server and client.

What I didn't

  • Expects you to write code; there is no big app catalog to click through.
  • The free tier caps workspaces at 3 and job history at 30 days.
  • Seat pricing: builders $20 and non-builders $10 a month.

Best for: engineering teams that want scripts, workflows and internal tools on one self-hosted platform.

Which to choose

  • Choose n8n for the biggest community and integration directory, and if the license terms fit your use.
  • Choose Activepieces for an MIT-licensed visual builder that non-developers can run.
  • Choose Windmill if your team writes code and wants scripts, flows and internal apps together.

Community editions are free to self-host in all three, so budget for the server and upgrades, not only the plan.

Where viaSocket fits

viaSocket is a hosted option rather than a self-hosted one, so it suits teams that would rather not run servers. It covers the same ground as these tools: triggers, actions and AI agents.

FAQ

Which is cheapest to self-host?

The Community editions of all three are free to run, so the cost is your server and upgrade time. Paid tiers add support and enterprise features.

Which is better, n8n, Activepieces or Windmill?

It depends on the team. n8n has the largest community, Activepieces has the most permissive license for a visual builder, and Windmill suits developers who want code-first workflows.

Is n8n open source?

n8n describes itself as fair-code under the Sustainable Use License, which is source-available rather than OSI open source. Files marked .ee need an enterprise license.

Is Activepieces free to self-host?

Yes. The core is MIT-licensed and the Community edition is free to run with Docker Compose. Code in its ee folders has a separate license.

Does Windmill charge per execution?

No. Its pricing page lists unlimited executions on both the free and Enterprise plans. Paid plans charge per builder and non-builder seat, plus compute.

Do all three support MCP?

Yes. n8n offers an instance-level MCP server, Activepieces has an MCP server, and Windmill works as both an MCP server and client.
