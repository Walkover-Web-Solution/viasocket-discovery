Short answer: Arcade centres on per-user authorization, Composio on a hosted tool catalog, Metorial on an MCP gateway with call logs, Nango on integration code you own, and Pipedream Connect on managed auth embedded in your app. There is no single best. Pick by what you want to own: the permissions, the catalog, the gateway, the code or the auth flow.

The five are listed alphabetically, not ranked.

What it's like to use these five platforms

The quickest way to sort them is by what they ask you to own. Arcade asks about the user's permissions, Composio hands you a catalog, Metorial puts a gateway in front of your tools, Nango gives you the code, and Pipedream Connect gives you the auth plumbing for your own app.

Arcade

Arcade's quickstart centres on the user. You need an API key and a user ID, and a helper checks whether a tool needs authorization, prints a link for the user and waits. That is the product in miniature: agents acting for one specific person, with authorization through your identity provider.

What I liked

  • The agent acts as the signed-in user, with each action scoped.
  • Client libraries in Python, TypeScript and Java.
  • Enterprise runs in your VPC or fully air-gapped.

What I didn't

  • The authorization step is extra ceremony for single-user agents.
  • 2,000 free tool calls a month goes quickly for an agent that loops.
  • Identity-provider and self-hosted setups take extra testing.

Best for: agents that act for customers or employees, where per-user permissions matter.

Composio

Composio is the shortest path from nothing to an agent calling apps. You create a session for a user ID, pass its tools to your agent, and when a task needs an account the agent shares a Connect Link. You'll notice the quickstart is written for coding agents as well as people.

What I liked

  • Very little setup between you and a working agent.
  • A hosted MCP endpoint per session for Claude Desktop and Cursor.
  • The free plan pauses at its cap instead of billing overage.

What I didn't

  • The quickstart mixes coding-agent prompts into the human walkthrough.
  • Auth is the weak spot: expect to debug connected accounts and scopes.
  • No self-hosted option is listed.

Best for: teams that want an agent working across many apps on a hosted catalog.

Metorial

Metorial works as a gateway. You paste one MCP URL into a client, and Metorial adds access policies down to single tools and logs each call with the person's identity. There are JavaScript, TypeScript and Python SDKs and a CLI.

What I liked

  • One MCP URL to wire into any client.
  • Per-tool access policies and per-person call logs.
  • The catalog is Apache 2.0 licensed.

What I didn't

  • The Dev plan has no production access; going live means Scale at $250 a month.
  • Catalog counts and self-hosting terms vary between its own pages.
  • Upstream rate-limit and auth errors can surface as one generic failure.

Best for: teams that want an MCP gateway with per-tool policies and call logs.

Nango

Nango asks the most of you and gives you the most to own. The quickstart creates an agent session through POST /sessions that returns an MCP URL and a token. Underneath, every integration is a TypeScript function you version like application code.

What I liked

  • Integration logic is code you can read, review and version.
  • Scheduled, resumable syncs, not only tool calls.
  • The Logs tab shows every tool call, request and response.

What I didn't

  • Owning the code is a bigger commitment than a managed catalog.
  • Free self-hosting covers API auth and proxy only.
  • "Open source" in its marketing means the source-available Elastic License.

Best for: teams that want to own and version their integration code and need syncs.

Pipedream Connect

Pipedream Connect is built for embedding integrations in your own product. The quickstart has nine steps, including a project, an OAuth client and a short-lived token for each end user, and users connect through an SDK iframe or a hosted Connect Link.

What I liked

  • A very large catalog: 3,000+ APIs and 10,000+ MCP tools.
  • Short-lived per-user tokens created on your server.
  • SOC 2 Type 2 and GDPR on every plan.

What I didn't

  • Nine setup steps make it thorough rather than quick.
  • The free tier is development only; production starts at $99 a month billed annually.
  • Now part of Workday, which leaves the roadmap less certain.

Best for: developers who want managed auth across a large API catalog inside their own app.

Best AI agent integration platform by need

  • Agents acting for real users, with per-user permissions: Arcade.
  • A hosted catalog that gets an agent working across many apps: Composio.
  • An MCP gateway with per-tool policies and call logs: Metorial.
  • Code you read, change and version, plus data syncs: Nango.
  • Managed auth embedded in your own app across many APIs: Pipedream Connect.

All five list a free plan, so running two on your real workload costs little.

What to check before you pick

  • The billable unit. Tool calls, connections, external users and compute credits are not the same thing.
  • Production access. Pipedream's free tier and Metorial's Dev plan exclude it.
  • Self-hosting terms. Which plan includes it, and which features it leaves out.
  • Who owns the code. Hosted catalog or functions you version yourself.

FAQ

How do the free plans compare?

Arcade's Free plan includes 2,000 tool calls a month, Composio's Hobby plan 100,000, and Metorial's Dev plan 500,000 with no production access. Nango's free plan includes 10 connections, and Pipedream's free tier is for development only. The meters differ, so the plans do not compare directly.

Which ones can I self-host?

Arcade lists your VPC or air-gapped deployment on Enterprise. Metorial lists on-prem under Enterprise on its pricing page. Nango's free self-hosting covers API auth and proxy only, with full self-hosting and bring-your-own-cloud on Enterprise. Composio and Pipedream Connect do not list a self-hosted option.

Do all five support MCP?

Yes. Arcade delivers tools as MCP servers, Composio has a hosted endpoint per session, Metorial works as an MCP gateway, Nango has an MCP server, and Pipedream has an MCP server that cites 10,000+ tools.

Which ones are open source?

Composio's SDK repository and Arcade's arcade-mcp framework are MIT licensed, and Metorial's catalog is Apache 2.0. Nango is under the Elastic License, which is source-available, and Pipedream's components registry is described as source-available.

Is Pipedream owned by Workday?

Workday announced an agreement to acquire Pipedream, and its later release says Workday closed the acquisition.
