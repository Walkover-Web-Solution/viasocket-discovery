Short answer: there is no single best one, because the five split on what you want to own. For free call volume, Metorial lists 500,000 tool calls a month and Composio 100,000, against 2,000 on Arcade. Arcade is built around per-user authorization, Nango around integration code you own, and Pipedream Connect lists the largest catalog at 3,000+ APIs. Pipedream's free tier and Metorial's Dev plan both exclude production use.

This page covers Arcade, Composio, Metorial, Nango and Pipedream Connect, listed alphabetically, not ranked. It uses each vendor's pricing page, docs and repository, plus public discussions where they exist. We did not run these products, and vendor claims are attributed.

What users and the docs say

We read the docs and looked for public discussions. Independent head-to-head write-ups of these five are scarce: searches returned vendor pages, directories and listicles, so what follows rests on the docs, the repositories and attributed discussions.

  • Arcade. Per its quickstart, a helper checks whether a tool needs authorization, prints a link for the user and waits. The Free plan's 2,000 calls are a small test allowance, and the pricing page does not say what happens at the limit.
  • Composio. Per its quickstart, you create a session for a user ID and the agent shares a Connect Link when a task needs an account. The quickstart page also carries a prompt for coding agents beside the human walkthrough. Hobby usage pauses at the cap.
  • Metorial. Its homepage describes pasting one MCP URL into a client, and its docs list JavaScript, TypeScript and Python SDKs. Its own pages give different catalog counts, and its pricing page lists on-prem self-hosting under Enterprise while its comparison page says self-hosting does not need an enterprise contract. Check which applies to you.
  • Nango. Its quickstart creates an agent session through POST /sessions and returns an MCP URL and token; the Logs tab shows each tool call. In a Hacker News launch thread, commenters objected that the Elastic License is not OSI-approved open source, and one reported a year of stable OAuth use. That thread predates the current agent focus.
  • Pipedream Connect. Its quickstart has nine steps, including a project, an OAuth client and a short-lived token per end user. Workday's later release says it closed the acquisition of Pipedream. In the Hacker News thread on the announcement, commenters suggested other tools, and three said they work for or founded the product they suggested; no commenter reported on Pipedream Connect itself.

Which to choose

  • You want the most free calls and a hosted catalog: Composio's Hobby plan or Metorial's Dev plan, noting Metorial's Dev plan has no production access.
  • Your agents act for real users and you need permission checks when they act: Arcade.
  • You want code you can read, change and version, or you need syncs and self-hosting: Nango.
  • You want managed auth across the largest catalog and are fine with production on a paid plan: Pipedream Connect.
  • You want an MCP gateway with call logs that you can self-host: Metorial, after checking its self-hosting terms.

All five list a free plan, so running two on your real workload costs little. Check how each defines a billable call, connection or external user first.

FAQ

Which integration layer has the biggest free plan?

By tool calls, Metorial's Dev plan lists 500,000 a month and Composio's Hobby plan 100,000, against 2,000 on Arcade's Free plan. Metorial's Dev plan has no production access, and Nango and Pipedream meter different things, so the plans do not compare directly.

Which ones can I self-host?

Nango lists self-hosting and bring-your-own-cloud on Enterprise and offers limited free self-hosting. Arcade lists your VPC or air-gapped deployment on Enterprise. Metorial lists on-prem under Enterprise on its pricing page, while another page says no enterprise contract is needed. Composio's pricing page does not list self-hosting, and the Pipedream Connect docs do not mention it.

Do all five support MCP?

Each describes MCP support: Composio through a hosted endpoint per session, Arcade by delivering tools as MCP servers, Metorial as an MCP gateway, Nango through an MCP server, and Pipedream through an MCP server that cites 10,000+ tools.

Which ones are open source?

Composio's SDK repository and Arcade's arcade-mcp framework are MIT licensed, and Metorial's catalog is Apache 2.0. Nango is under the Elastic License, which is source-available, and Pipedream's components registry is described as source-available.

Is Pipedream owned by Workday?

Workday announced an agreement to acquire Pipedream, and its later release says it closed the acquisition.
