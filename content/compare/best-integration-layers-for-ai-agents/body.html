What it's like to use these five platforms

I found no independent head-to-head of these five, so what follows is one reviewer's read of how each is set up, priced and talked about. The quickest way to sort them is by what they ask you to own: the user's permissions, the tool catalog, the gateway, the code or the auth plumbing.

Arcade

Arcade's quickstart centres on the user. You need an account, an API key and a user ID, and a helper checks whether a tool needs authorization, prints a link for the user and waits. That is the product in miniature: agents acting for a specific person, with authorization through your identity provider (per Arcade). The open reports I found sit on the framework repository rather than the hosted service, and they involve the enterprise-flavoured parts, such as a blank Auth settings page in the dashboard and a Microsoft Entra ID authorization asking for a scope that cannot be changed, so test identity-provider setup early. The free plan's 2,000 calls a month is a small allowance for testing an agent that loops, and the pricing page does not say what happens at the limit.

Composio

Composio is the shortest path from nothing to an agent calling apps. You create a session for a user ID, and when a task needs an account the agent shares a Connect Link. You'll notice the quickstart carries a prompt for coding agents beside the human walkthrough, so expect to skim. The rough edges that show up publicly lean towards auth and connected accounts, such as an invalid-token error on valid connections for one tool and a connect error page that hides the provider's reason. They are individual reports, but it is where I would look first when something breaks. The free plan is generous at 100,000 tool calls a month, and it pauses at the cap instead of billing overage.

Metorial

Metorial's pitch is a gateway. You paste one MCP URL into a client, and it adds access policies down to single tools and a log of each call with the person's identity (per Metorial). It has JavaScript, TypeScript and Python SDKs and a CLI. The Dev plan is the most generous on calls at 500,000 a month, but it has no production access, one project, one environment and ten provider integrations, so it is for evaluating rather than shipping. Scale is $250 a month. Two things I would check before committing: its own pages give different catalog counts, and its pricing page lists on-prem self-hosting under Enterprise while its comparison page says self-hosting does not need an enterprise contract. Open reports on the repository concern error handling, with upstream rate-limit, availability and auth errors collapsed into one terminal failure and ordinary handler errors reaching the caller as a generic server error. If your agent has to retry on a rate limit, test that path.

Nango

Nango asks the most of you and gives you the most to own. The quickstart creates an agent session through POST /sessions that returns an MCP URL and a token, and the Logs tab shows each tool call, which is where I would debug. The product itself is TypeScript functions that you version like application code (per Nango), plus scheduled syncs. Self-hosting is where I would read carefully. Free self-hosting covers API auth and proxy only, full self-hosting is an Enterprise matter, and the open reports cluster there, including a connect link that sends users to Nango's cloud host and a request to clarify the self-hosted feature set. It is under the Elastic License, which is source-available, and early commenters objected to the open-source label. Feedback on its OAuth has been positive, including a report of a year of stable use, though that was about an earlier version of the product.

Pipedream Connect

Pipedream Connect's quickstart has nine steps, including a project, an OAuth client and a short-lived token for each end user. That is thorough rather than quick. The free tier is development only, so production starts at $99 a month billed annually. One public report says File Stash in development asks for an upgrade although the docs say all Connect features are available in development, so test anything you depend on. Workday says it closed its acquisition of Pipedream, and I found no hands-on reports of Connect in the public discussion of the deal, so ask about roadmap and pricing before you build on it.

Best AI agent integration platform by need

  • Most free calls, hosted: Composio Hobby, or Metorial Dev (no production).
  • Agents acting for real users: Arcade, for per-user authorization.
  • Code you read, change and version: Nango.
  • Managed auth across many APIs: Pipedream Connect, with production on a paid plan.
  • MCP gateway with call logs: Metorial, after checking its self-hosting terms.

All five list a free plan, so running two on your real workload costs little.

What to check before you pick

  • The billable unit. Tool calls, connections, external users and compute credits are not the same thing.
  • Production access. Pipedream's free tier and Metorial's Dev plan exclude it.
  • Self-hosting terms. Which plan includes it, and which features it leaves out.
  • Who owns the code. Hosted catalog or functions you version yourself.

FAQ

Which AI agent integration platform has the biggest free plan?

By tool calls, Metorial's Dev plan lists 500,000 a month and Composio's Hobby plan 100,000, against 2,000 on Arcade's Free plan. Metorial's Dev plan has no production access, and Nango and Pipedream meter different things, so the plans do not compare directly.

Which ones can I self-host?

Nango's docs say free self-hosting covers API auth and proxy only, and list full self-hosting and bring-your-own-cloud on Enterprise. Arcade lists your VPC or air-gapped deployment on Enterprise. Metorial lists on-prem under Enterprise on its pricing page, while another page says no enterprise contract is needed. Composio's pricing page does not list self-hosting, and the Pipedream Connect docs do not mention it.

Do all five support MCP?

Each describes MCP support: Composio through a hosted endpoint per session, Arcade by delivering tools as MCP servers, Metorial as an MCP gateway, Nango through an MCP server, and Pipedream through an MCP server that cites 10,000+ tools.

Which ones are open source?

Composio's SDK repository and Arcade's arcade-mcp framework are MIT licensed, and Metorial's catalog is Apache 2.0. Nango is under the Elastic License, which is source-available, and Pipedream's components registry is described as source-available.

Is Pipedream owned by Workday?

Workday announced an agreement to acquire Pipedream, and its later release says Workday closed the acquisition.
