Short answer: there is no single best AI agent integration platform, because the five split on what you want to own. Metorial lists 500,000 free tool calls a month and Composio 100,000, against 2,000 on Arcade. Arcade centres on per-user authorization and Nango on code you own. Pipedream Connect lists 3,000+ APIs, counted differently.

This page covers five AI agent integration platforms, which some vendors call integration layers: Arcade, Composio, Metorial, Nango and Pipedream Connect, listed alphabetically, not ranked. We review every app we compare by using it and by reading what its docs and its users say. The specifics below come from each vendor's docs, pricing page and repository and from public reports such as GitHub issues and Hacker News, with the source type named each time. Where evidence is thin, we say so. Vendor claims are attributed.

What users and the docs say

Independent head-to-head write-ups of these five are scarce: searches returned vendor pages, directories and listicles, so evidence on day-to-day use is thin. What follows rests on the docs, the repositories' public issues and attributed discussions, and each point names its source type.

  • Arcade. From its quickstart: a helper checks whether a tool needs authorization, prints a link for the user and waits. From the pricing page: the Free plan's 2,000 calls are a small test allowance, and the page does not say what happens at the limit. From the arcade-mcp issues (framework only): a blank Auth settings dashboard page (#942) and Microsoft Entra ID authorization requesting a scope that cannot be changed (#777).
  • Composio. From its quickstart: you create a session for a user ID and the agent shares a Connect Link when a task needs an account; the page also carries a prompt for coding agents beside the human walkthrough. From the pricing page: Hobby usage pauses at the cap. From the GitHub issues: recent open reports lean towards auth and connected accounts, such as an invalid-token error on valid Trello connections (#4962) and a connect error page that hides the provider's error detail (#5038).
  • Metorial. From its homepage: you paste one MCP URL into a client; its docs list JavaScript, TypeScript and Python SDKs. Its own pages give different catalog counts, and its pricing page lists on-prem self-hosting under Enterprise while its comparison page says self-hosting does not need an enterprise contract, so check which applies to you. From the GitHub issues: upstream 429, 503 and 401 responses turned into a terminal error (#167) and plain handler errors reaching the caller as "Internal server error" (#168), both open.
  • Nango. From its quickstart: it creates an agent session through POST /sessions and returns an MCP URL and token, and the Logs tab shows each tool call. From the GitHub issues: open reports cluster around self-hosting, such as a connect link pointing at Nango's cloud host (#7945) and a request to clarify the self-hosted feature set (#5536). From Hacker News: in a launch thread, commenters objected that the Elastic License is not OSI-approved open source and one reported a year of stable OAuth use; that thread predates the current agent focus.
  • Pipedream Connect. From its quickstart: nine steps, including a project, an OAuth client and a short-lived token per end user. From the GitHub issues (mostly the components registry): File Stash in development returning a 401 that asks for an upgrade, although the docs say all Connect features are available in development (#21975). From the Workday release: it says Workday closed its acquisition of Pipedream. From Hacker News: commenters on the announcement suggested other tools, three said they work for or founded the product they suggested, and none reported on Pipedream Connect itself.

Best AI agent integration platform by need

  • Most free calls, hosted: Composio Hobby, or Metorial Dev (no production).
  • Agents acting for real users: Arcade, for per-user authorization.
  • Code you read, change and version: Nango.
  • Managed auth across many APIs: Pipedream Connect, with production on a paid plan.
  • MCP gateway with call logs: Metorial, after checking its self-hosting terms.

All five list a free plan, so running two on your real workload costs little.

What to check before you pick

  • The billable unit. Tool calls, connections, external users and compute credits are not the same thing.
  • Production access. Pipedream's free tier and Metorial's Dev plan exclude it.
  • Self-hosting terms. Which plan includes it, and which features it leaves out.
  • Who owns the code. Hosted catalog or functions you version yourself.

FAQ

Which AI agent integration platform has the biggest free plan?

By tool calls, Metorial's Dev plan lists 500,000 a month and Composio's Hobby plan 100,000, against 2,000 on Arcade's Free plan. Metorial's Dev plan has no production access, and Nango and Pipedream meter different things, so the plans do not compare directly.

Which ones can I self-host?

Nango's docs say free self-hosting covers API auth and proxy only, and list full self-hosting and bring-your-own-cloud on Enterprise. Arcade lists your VPC or air-gapped deployment on Enterprise. Metorial lists on-prem under Enterprise on its pricing page, while another page says no enterprise contract is needed. Composio's pricing page does not list self-hosting, and the Pipedream Connect docs do not mention it.

Do all five support MCP?

Each describes MCP support: Composio through a hosted endpoint per session, Arcade by delivering tools as MCP servers, Metorial as an MCP gateway, Nango through an MCP server, and Pipedream through an MCP server that cites 10,000+ tools.

Which ones are open source?

Composio's SDK repository and Arcade's arcade-mcp framework are MIT licensed, and Metorial's catalog is Apache 2.0. Nango is under the Elastic License, which is source-available, and Pipedream's components registry is described as source-available.

Is Pipedream owned by Workday?

Workday announced an agreement to acquire Pipedream, and its later release says Workday closed the acquisition.
