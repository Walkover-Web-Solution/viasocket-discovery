## Short answer
Roo Code shut down on 15 May and its repo is archived. Zoo Code is a community fork that imports Roo settings and keeps its modes. Cline, Roo's upstream, is the largest project, with 71.5k GitHub stars. Kilo Code has a step-by-step Roo migration guide and a $15 Teams plan. All three are free with your own API keys.

## Zoo Code vs Cline vs Kilo Code: what they're like after Roo
By Abhijeet Singh. All three are open-source agents in your editor, and all three accept your own keys, so the switch is mostly about your modes, rules and MCP servers. Pick by how much of your Roo setup you want to keep.

### Zoo Code
Zoo Code is the closest thing to keeping Roo: the same settings structure, Architect, Code and Debug modes, custom modes and MCP, maintained by developers who contributed to Roo. It ships often, and it is still a young project.
What I liked:
- Export your Roo settings and import them; modes and model configs carry over.
- Per-mode MCP restrictions and Orchestrator workflows, per Zoo.
- Frequent releases since the fork began in late April.
What I didn't:
- The smallest community here, at 2.1k GitHub stars.
- The JetBrains plugin is still in beta.
- No enterprise plan, SSO or compliance claims listed on the site.
Best for: Roo users who want their modes and workflow back with the least change.

### Cline
Cline is where Roo started, and it has by far the biggest community. Its Plan and Act modes are simpler than Roo's mode system, so expect to rebuild custom modes as rules or prompts. It runs in more editors than the others.
What I liked:
- The largest project here: 71.5k stars and frequent releases.
- VS Code, JetBrains, Cursor and Windsurf, plus a CLI and SDK.
- Enterprise can run in your VPC, on-prem or air-gapped.
What I didn't:
- Moving from Roo is manual: rename .roorules and recreate modes.
- The most-discussed open issues concern terminal integration reliability.
- Some Roo users say it works less well with certain models.
Best for: developers who want the most established open-source agent and broad editor support.

### Kilo Code
Kilo Code is the most complete platform of the three, with cloud agents, code review and a model gateway around the open-source extension. Its migration guide maps every Roo file, but the new extension is a rebuild and some Roo features are not there yet.
What I liked:
- A documented Roo migration path covering rules, modes and MCP config.
- 500+ models at provider rates, or local models for free.
- A clear Teams plan at $15 a user a month.
What I didn't:
- Orchestrator mode is deprecated and codebase indexing is not yet ported.
- API keys do not transfer from Roo.
- Buying gateway credits adds a 5% processing fee.
Best for: teams that want an open-source agent plus managed billing, cloud agents and team plans.

## Which to choose
- Choose Zoo Code if you want Roo's modes and settings back with almost no change.
- Choose Cline if you want the largest, most established project and can rebuild your modes.
- Choose Kilo Code if you want a guided migration plus team plans and cloud agents.
Back up your .roomodes, rules and MCP config before you switch: every path above reuses them.

## FAQ
Q: Is Roo Code still available?
A: No. The extension was shut down on 15 May, and its GitHub repo is archived and read-only. The README points users to Zoo Code and Cline, and roocode.com now redirects to the team's new product, Roomote.
Q: What is the closest alternative to Roo Code?
A: Zoo Code, a community fork that keeps Roo's settings structure and modes. You export settings from Roo and import them into Zoo.
Q: Can I move my Roo modes to Kilo Code?
A: Yes. Kilo's guide has you copy .roomodes to .kilocodemodes, and a first-launch wizard converts them. Rules and MCP config move too, but API keys do not.
Q: Is Cline free?
A: Yes. The open-source extension has no subscription or seat fees; you bring your own keys or buy inference credits at cost. Enterprise pricing is custom.
Q: Do these alternatives support MCP?
A: All three do. Zoo Code can restrict MCP servers per mode, and Kilo's migration carries over Roo's MCP config.
