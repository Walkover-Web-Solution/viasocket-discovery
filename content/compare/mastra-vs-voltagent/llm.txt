# Mastra vs VoltAgent: features, pricing and which to use

## Short answer
Mastra and VoltAgent are open-source TypeScript frameworks for building AI agents. Mastra (Apache 2.0) is the larger, batteries-included toolkit with its own Studio. VoltAgent (MIT) is lighter and pairs with the VoltOps console for traces and operations. Both frameworks are free and both support MCP; you pay only for the optional hosted platform.

## Mastra vs VoltAgent: what they're like to use
By Abhijeet Singh. Both get you from an empty folder to a working TypeScript agent quickly. The difference is the center of gravity: Mastra puts the framework first, VoltAgent puts the console in the loop.

### Mastra
Feels like a framework with a plan. npm create mastra@latest scaffolds an agent with memory, and Studio opens against it with traces, scorers and datasets in one place. The trade is that you work the way it expects.
What I liked:
- Agents, workflows, memory, RAG, evals and MCP in one package.
- Studio runs locally with traces, scorers and experiments.
- Deploys to Vercel, Netlify, Cloudflare or inside Next.js.
What I didn't:
- Opinionated: designs outside its patterns take more work.
- Memory needs a storage provider before it works.
- Code under ee/ is source-available, not Apache 2.0.
Best for: TypeScript teams that want one batteries-included toolkit.

### VoltAgent
Starts from visibility. npm create voltagent-app@latest starts a local server and points you to the VoltOps console, where you chat with the agent and read each run as a trace.
What I liked:
- Run-by-run visual traces with tool inputs and outputs.
- MIT licensed end to end.
- Supervisor and sub-agent teams built into the core.
What I didn't:
- Smaller community: about 152,000 monthly npm downloads vs 8.5 million.
- The free console plan allows 250 traces a month.
- Docs are split across separate sites.
Best for: teams that want a lighter MIT framework with traces beside the code.

## Which to choose
- Choose Mastra for the broadest built-in toolkit, a larger community and a local Studio.
- Choose VoltAgent for an MIT framework with chain-style workflows and a trace console.
Both are free, so build the same small agent in each before paying for any hosted plan.

## FAQ
Q: What is the difference between Mastra and VoltAgent?
A: Both are open-source TypeScript agent frameworks. Mastra is the larger, batteries-included toolkit with its own Studio. VoltAgent is lighter and pairs with the VoltOps console for traces and operations.
Q: Are Mastra and VoltAgent free?
A: Yes. Both frameworks are free to self-host. The hosted platforms have free plans: Mastra Starter and VoltOps Developer.
Q: Are they open source?
A: VoltAgent is MIT. Mastra's core is Apache 2.0; code in its ee/ directories is source-available.
Q: Do both support MCP?
A: Yes, both as an MCP client and as an MCP server.
Q: Which is more popular?
A: Mastra: about 29.2k GitHub stars and 8.5 million monthly npm downloads. VoltAgent: about 10.9k stars and 152,000 downloads.
