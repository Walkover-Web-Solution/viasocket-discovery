Short answer: Composio has the bigger free allowance, with 100,000 tool calls a month on its Hobby plan against 2,000 on Arcade's Free plan. What users and the docs say

We read each quickstart and looked for public discussions. Independent hands-on write-ups comparing these two are scarce: searches returned mostly vendor pages and directory sites. What follows is what the docs show and what others have said, with the source named each time.

Composio

Per its quickstart, you install the packages for your framework, add API keys to a .env file, create a session for a user ID and pass the session's tools to your agent. When a task needs an account, the agent shares a Connect Link, the user approves it and the agent carries on. Python examples cover the OpenAI Agents SDK and the Claude Agent SDK; TypeScript examples add the Vercel AI SDK.

The same quickstart page also carries a prompt for coding agents and a list of rules for AI code generators beside the human walkthrough, so a person reading it has to skip parts. On cost, the pricing page says Hobby usage pauses at the cap instead of billing overage.

Arcade

Per its quickstart, you need an Arcade account, an API key and a user ID, then install the client for Python, TypeScript or Java. A helper function checks whether a tool needs authorization, prints a link for the user and waits. Tools that need no authorization run directly. The example chains a Google News search, a Google Docs write and a Gmail send.

The Free plan's 2,000 monthly calls are a small allowance for testing an agent that loops, and the pricing page does not say what happens at the limit. Arcade also announced it acquired Smithery, a registry and hosting platform for MCP servers, and its post announces no changes to Smithery's product or pricing.

What each says about the other

Arcade's comparison page says Composio typically acts with shared credentials, where Arcade acquires each user's OAuth tokens at runtime. It also reports, from its own benchmark of 8 CRM queries, 7,426 tokens for its Attio toolkit against 747,083 for Composio's. Composio's comparison page describes Arcade's short-lived, scoped tokens as limiting exposure, says Arcade shows strong token efficiency in specific workflows, and says its own tokens are stored with AES-256-GCM envelope encryption. These are each vendor's claims about a competitor and we did not verify them.

A dev.to analysis describes Composio's abstractions as opinionated, which can feel heavy if you only need OAuth for a couple of tools, and says Arcade checks permissions when the agent acts and has a smaller connector set. The article's account promotes a different product and discloses no affiliation, so read it as one opinion.

Which to choose

If you want an agent working across many apps quickly and a large free allowance, Composio is the easier start. If your agents act for real users and you need permission checks at the moment of action, identity-provider integration or an air-gapped deployment, Arcade is built for that. Both have free plans, and the per-call meters differ, so run each on your own workload before you decide.

FAQ

What is the main difference between Composio and Arcade?

Composio is a hosted catalog of app tools with managed auth. Arcade describes itself as an actions runtime that handles user authorization, policy and tool execution, with delegated per-user permissions.

Do Composio and Arcade both have a free plan?

Yes. Composio's Hobby plan includes 100,000 tool calls and 50,000 trigger events a month. Arcade's Free plan includes 2,000 tool calls a month.

Do both support MCP?

Yes. Composio exposes sessions through a hosted MCP endpoint. Arcade delivers its tools as MCP servers and lets you register your own.

Can I self-host Composio or Arcade?

Arcade's pricing page lists Arcade Cloud, your VPC or fully air-gapped deployment on Enterprise, and its docs describe self-hosting with Helm. Composio's pricing page does not list a self-hosted option.

Are Composio and Arcade open source?

Composio's SDK repository and Arcade's arcade-mcp framework are both MIT licensed. Arcade's prebuilt catalog is a hosted offering.
