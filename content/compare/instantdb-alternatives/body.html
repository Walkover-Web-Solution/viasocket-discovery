Convex vs PowerSync vs Supabase: what they're like to use

Convex replaces the backend, PowerSync syncs yours, Supabase adds live updates to Postgres.

Convex

What stood out to me is that Convex is closest to Instant's query-and-mutate model: TypeScript queries, and the UI updates on its own. It replaces the database and server layer, so moving means rewriting data access.

What I liked

  • Queries rerun and push to subscribers via useQuery.
  • Mutations are serializable transactions that retry on conflicts.
  • Free tier covers 1M function calls and 1,000 concurrent sessions.

What I didn't

  • FSL license: source available, with Apache 2.0 as the future license.
  • Pro is priced per developer, so team size drives the bill.
  • No local database: the client queues mutations in memory.

Best for: teams that want a hosted TypeScript backend with live queries and transactions.

PowerSync

PowerSync does not replace your database, and I would weigh that first. It keeps a local SQLite copy on each device, which suits offline apps. You keep a backend and write the upload path.

What I liked

  • Sources include Postgres, MongoDB, MySQL and SQL Server.
  • SDKs for web, React Native, Flutter, Swift, Kotlin and .NET.
  • The Service is Apache-2.0 and self-hostable with Docker.

What I didn't

  • You write the code that applies queued writes to your backend.
  • Free projects are deactivated after inactivity.
  • Self-hosted instances have no web dashboard yet.

Best for: mobile or offline-first apps that already run their own database.

Supabase

I would call Supabase the most conventional move: one Postgres project with Realtime, auth and storage, plus an importer for Instant backups that may not work for all users.

What I liked

  • Broadcast, Presence and Postgres Changes cover live data.
  • The importer maps Instant namespaces to tables and files to Storage.
  • Free plan has 50,000 monthly active users and 500 MB of database.

What I didn't

  • Postgres Changes runs on one thread; Broadcast advised past about 3,000 subscribers.
  • Offline sync is not in Realtime; PowerSync has a Supabase guide.
  • Self-hosting runs one project and omits branching and managed backups.

Best for: teams that want SQL, row level security and one platform for auth, storage and realtime.

Which to choose

  • Choose Convex if you want a hosted backend with reactive TypeScript queries and can rewrite data access.
  • Choose PowerSync if the app must work offline and you already run Postgres, MongoDB, MySQL or SQL Server.
  • Choose Supabase if you want Postgres and SQL, or its importer for Instant backups.

Export your Instant data first and test one real screen before cutover.

FAQ

What is happening to Instant (InstantDB)?

Instant says its team joined OpenAI and new signups are closed. Existing users should migrate within 12 months, cloud apps shut down on August 31, and backups stay for 12 more months.

Can I import Instant data into Supabase?

Yes, Supabase publishes an importer: namespaces become tables, users become Auth accounts and files go to Storage. Supabase says it may not work for all users.

How much do Convex, PowerSync and Supabase cost?

Convex Pro is $25 per developer per month, Supabase Pro $25 and PowerSync Pro $49. All three have a free plan.

Which alternative works offline?

PowerSync keeps a local SQLite copy on each client. Convex documents an in-memory mutation queue; Supabase Realtime lists no offline sync.
